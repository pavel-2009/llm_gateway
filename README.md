# LLM Gateway

Базовый HTTP API шлюза доступен без авторизации:

| Метод | Путь | Назначение |
| --- | --- | --- |
| `POST` | `/generate` | Генерация текста |
| `POST` | `/extract` | Извлечение структурированных данных |
| `POST` | `/stream` | Потоковая генерация текста |

Все три метода принимают JSON с полем `prompt`, например:

```json
{"prompt": "Привет"}
```

Запуск локального сервера:

```bash
uv run uvicorn main:app --reload --app-dir src
```

Интерактивная документация FastAPI: `/docs`.

## Логирование

События запроса логируются на уровнях API, gateway, resolver, policy pipeline и
адаптера провайдера. Каждому HTTP-запросу присваивается `request_id`, который
помогает связать записи; логируются выбранная модель, fallback/retry, длительность,
тип ошибки и размер результата. Тексты запросов и ответов, а также секреты, в
логи не записываются. По умолчанию включён уровень `INFO`.
